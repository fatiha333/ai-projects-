Project 3 — DealDial: AI Client Acquisition Agent
Stop hunting clients manually. DealDial finds potential businesses 
that need your service, generates a hyper-personalized cold call 
script, and delivers it in a human-sounding AI voice — ready to pitch.

How it works:
1. Describe your service and target niche
2. AI hunts real businesses using live web search
3. AI generates a personalized pitch script for each client
4. ElevenLabs converts the pitch to natural human voice audio
